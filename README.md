## 📌 Overview
This repository contains my data analytics project for the **Bright Coffee Shop Case Study (2026)**.  
The project analyzes daily transactional data from a coffee shop to uncover insights that help the CEO grow revenue and improve product performance.  

The workflow involved:
- **Data Cleaning** in Databricks (handling inconsistent formats, creating time buckets, computing totals).  
- **Data Visualization** using Excel, Power BI, Google Data Studio, and Loveable dashboards.  
- **Presentation** of insights and recommendations in Microsoft PowerPoint.  
- **Planning & Architecture** diagrams created in Miro.  

---

## 🎯 Objectives
The case study required answering key business questions:
- Which products generate the most revenue?  
- What time of day the store performs best?  
- How do sales trends vary across products and time intervals?  
- What recommendations can improve sales performance?

## 📊 Key Insights
- **Top Products**: Certain product categories consistently drive the highest revenue.  
- **Peak Sales Times**: The store performs best during specific time intervals (e.g., morning rush).  
- **Sales Trends**: Clear seasonal and time-based patterns were identified.  
- **Recommendations**:
  - Launch marketing campaigns during slow time slots  
  - Stock more of the best-selling items  
  - Promote underperforming products with discounts or bundles  
  - Implement loyalty programs during peak hours
