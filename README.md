## 📌 Overview
This repository contains my data analytics project for the **Bright Coffee Shop Case Study (2026)**.  
The project analyzes daily transactional data to uncover insights that help the CEO grow revenue and improve product performance.

---

## 🎯 Objectives
- Identify products generating the most revenue
- Determine peak sales times during the day
- Analyze sales trends across products and time intervals
- Provide actionable recommendations to improve sales performance

---

## 🛠️ Tools & Technologies
- **Data Processing**: Databricks, SQL  
- **Data Visualization**: Excel, Power BI, Google Data Studio, Loveable  
- **Presentation**: Microsoft PowerPoint  
- **Planning & Architecture**: Miro
